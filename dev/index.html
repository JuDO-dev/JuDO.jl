JuDO.jl

Julia for Dynamic Optimization

JuDO is a domain-specific modeling language for dynamic optimization. It extends the syntax of JuMP.jl to support infinite-dimensional optimization variables and differential equations.

Installation

using Pkg
Pkg.add("JuDO")

JuDO.phase_final — Method
phase_final(t::PhaseVarRef)

Returns the final time of the phase t.

  • If the final time is fixed (e.g., final(t) == 10), returns that value.
  • If the final time is free/optimized (e.g., final(t) <= 10), queries the solver for the result.
